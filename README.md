## 📊 Crypto Multi-Factor Scorer

CoinBeacon-inspired multi-factor scoring engine for crypto futures.
Uses **public Binance API** — no keys required.

## Features
- 16+ indicators (RSI, MACD, EMA, Bollinger, Supertrend, ADX, OBV, VWAP, Stoch RSI, Taker flow, OI, Funding)
- 5 weighted factor buckets (Context, Event, Participation, Risk, Alignment)
- Multi-timeframe analysis (15m / 1h / 4h / 1d)
- Live Streamlit dashboard with Plotly charts
